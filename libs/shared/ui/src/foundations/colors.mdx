  Object.fromEntries(

  );

# Colors

The GDG Wrocław palette, sourced from the Figma **Colors** page and defined in
[`@gdg-wroclaw/shared-ui-tokens`](https://github.com/AdrianRomanski/gdg-wroclaw/tree/main/libs/shared/ui-tokens)
(see ADR-0003). Use the CSS custom properties, never raw hex values:

```css
.card {
  background: var(--gdg-color-pastel-blue);
  color: var(--gdg-color-black-02);
}
```
