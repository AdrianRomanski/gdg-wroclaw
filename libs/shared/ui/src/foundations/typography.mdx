# Typography

Sourced from the Figma **Typography** page (Google Sans frames) and defined in
[`@gdg-wroclaw/shared-ui-tokens`](https://github.com/AdrianRomanski/gdg-wroclaw/tree/main/libs/shared/ui-tokens)
(see ADR-0005). Fonts are self-hosted, so no requests go to Google servers.

| Family | Font                                                              | Token                    |
| :----- | :---------------------------------------------------------------- | :----------------------- |
| Sans   | <span style={{ font: fontVar('paragraph-6') }}>Google Sans</span> | `--gdg-font-family-sans` |
| Mono   | <span style={{ font: fontVar('mono-6') }}>Google Sans Code</span> | `--gdg-font-family-mono` |

Every text style is a `font` shorthand token combining weight, size, line height and family:

```css
.event-title {
  font: var(--gdg-font-heading-3);
}
```

The underlying primitives (`--gdg-font-size-1…9`, `--gdg-line-height-1…9`, `--gdg-font-weight-regular|bold`,
`--gdg-font-family-sans|mono`) are available for one-off combinations.
