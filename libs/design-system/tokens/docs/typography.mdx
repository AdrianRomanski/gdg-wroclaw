# Typography

Sourced from the Figma **Typography** page (Google Sans frames) and defined in
[`@gdg-wroclaw/design-system-tokens`](https://github.com/AdrianRomanski/gdg-wroclaw/tree/main/libs/design-system/tokens)
(see ADR-0005 and ADR-0008). Fonts are self-hosted, so no requests go to Google servers.

| Family | Font                                                                  | Token                    |
| :----- | :-------------------------------------------------------------------- | :----------------------- |
| Sans   | <span style={{ font: cssVar('font.paragraph-6') }}>Google Sans</span> | `--gdg-font-family-sans` |
| Mono   | <span style={{ font: cssVar('font.mono-6') }}>Google Sans Code</span> | `--gdg-font-family-mono` |

Every text style is a `font` shorthand token combining weight, size, line height and family:

```css
.event-title {
  font: var(--gdg-font-heading-3);
}
```

The underlying primitives (`--gdg-font-size-1…9`, `--gdg-line-height-1…9`, `--gdg-font-weight-regular|medium|bold`,
`--gdg-font-family-sans|mono`) are available for one-off combinations.
